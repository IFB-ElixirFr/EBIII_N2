Qu’est-ce qu’une étude d’association pangénomique ?

Une étude d’association pangénomique quantifie l’association statistique entre les variations génétiques et les phénotypes.

Un phénotype, également appelé trait, peut être toute propriété mesurée ou observée d’un individu.

Les phénotypes sont par exemple des caractères quantitatifs tels que la taille ou la concentration de particules de cholestérol dans le plasma, ou des caractères binaires tels que les diagnostics de psoriasis ou de schizophrénie.

🎯 Les objectifs d’une GWAS :

  • Mieux comprendre la base génétique des maladies complexes.
  • Proposer de nouvelles cibles thérapeutiques
  • Prédire le phénotype/ le risque génétique.

Exemple GWAS Migraine (phénotype binaire)

Hautakangas et al. (2022) ont combiné les données génétiques de 102 000 cas de migraine et de 771 000 témoins provenant de 25 études.

123 régions du génome ont montré une association statistique convaincante avec la migraine.

Deux de ces 123 régions contenaient des gènes (CALCA/CALCB et HTR1F) qui sont la cible de thérapies moléculaires récentes contre la migraine.

Enrichissement des signaux à proximité des gènes actifs dans le système vasculaire, mais aussi dans le système nerveux central. Cela constitue une preuve biologique que la migraine est un trouble neuro-vasculaire, et non seulement vasculaire ou neuronal.

L’équilibre de Hardy-Weinberg I

On considère un SNP biallèlique.

L’allèle mineur (le - fréquent dans la pop°) est appelé allèle 1

L’allèle majeur (le + fréquent dans la pop°) est appelé allèle 0.

Rmq : pas de règle générale d’autant plus que cela peut changer d’une population à l’autre.

Il y a donc 3 génotypes possibles à ce locus dans la pop°.

On code chaque génotype par le nb de copies de l’allèle 1 qu’il contient :

  • 0 : homozygote pour l’allèle majeur 0

  • 1 : hétérozygote

  • 2 : homozygote pour l’allèle mineur 1.

L’équilibre de Hardy-Weinberg II

On appelle \(f\) la fréquence de l’allèle mineur (MAF).

On appelle pop° de Hardy-Weinberg, une pop° idéale s’accouplant au hasard sans sélection, migration ou dérive génétique.

L’équilibre de Hardy-Weinberg III

Supposons qu’à ce locus, les deux allèles d’un individu sont échantillonnés au hasard dans une pop° HW, alors les fréquences relatives des génotypes suivent la distribution binomiale \(Bin(2,f)\) :

Génotypes

Fréquences attendues

d’après la loi \(Bin(2,f)\)
0 \((1-f)²\)
1 \(2f(1-f)\)
2 \(f²\)

L’équilibre de Hardy-Weinberg IV

Ces fréquences sont appelées fréquences génotypiques de l’équilibre de Hardy-Weinberg (HWE) (ou proportions HW) et définissent les fréquences génotypiques théoriques d’équilibre en fonction de la MAF \(f\) dans une pop° HW.

Dans la pratique, la plupart des variants dans les populations humaines suivent approximativement le modèle HWE.

Les écarts à HWE d’origine naturelle

Des écarts évidents par rapport au HWE pourraient indiquer:

  • une structure de pop° récente : deux pop° se sont mélangées,

  • un accouplement assortatif : les individus ont tendance à s’accoupler avec des partenaires qui leur ressemblent par certaines propriétés,

  • une sélection naturelle : le génotype 1 est très avantageux tandis que le génotype 2 est létal et donc complètement absent de la population.

Les écarts à HWE d’origine technique

Le calling des variants peut entrainer des écarts par rapport à HWE :

  • mauvaise qualité des données.

  • SNP multi-alléliques

Exclusions des variants qui ne suivent pas les fréquences HWE lors du contrôle de la qualité.

Incohérences liées au sexe

Le flag --check-sex de PLINK (notamment PLINK v1.9, mais aussi disponible dans PLINK2) est utilisé pour vérifier la concordance entre le sexe déclaré (dans le fichier .fam ou .psam) et le sexe biologique déduit des données génotypiques, principalement à partir des SNPs situés sur le chromosome X.

--check-sex évalue le rapport d’hétérozygotie sur le chromosome X pour chaque individu.

  • Hommes (XY) devraient avoir peu ou pas d’hétérozygotie sur X.

  • Femmes (XX) devraient avoir des niveaux normaux d’hétérozygotie.

Sortie PLINK pour --check-sex

Fichier .sexcheck contenant les colonnes suivantes :

  • FID, IID,

  • PEDSEX : sexe indiqué dans le fichier .fam ou .psam

  • SNPSEX : sexe déduit des génotypes

  • STATUS : OK ou PROBLEM

  • F : coefficient d’homozygotie sur le chromosome X.

La statistique F

La statistique F rapportée par plink --check-sex est une estimation de la proportion d’homozygotie sur les SNPs du chromosome X. Elle est dérivée d’une formule classique de Wright (coefficient de fixation) :

\(F=\frac{H_{exp} - H_{obs}}{H_{exp}}\)​​

  • \(H_{obs}\)​ : proportion d’hétérozygotes observés

  • \(H_{exp}​\) : proportion d’hétérozygotes attendus sous HW

Interprétation de stat F

Valeur de F Interprétation probable Sexe génétique
~1.0 Homozygote complet sur X → Homme 1 (Male)
~0.0 Hétérozygotie normale → Femme 2 (Female)
Entre 0.2 et 0.8 Ambigü ou problème Indéterminé ou erreur

Le test HWE

Test du \(\chi²\) à 1 df où les comptages attendus sont calculés en supposant HWE compte tenu des fréquences des allèles.

\(N\) individus d’une pop°, \(n_0\), \(n_1\), \(n_2\) génotypes observés pour les génotypes 0, 1 et 2, respectivement, avec \(N=n_0+n_1+n_2\).

estimation de \(f\) dans la pop° comptages attendus des génotypes
\(\hat{f}=\frac{n_1+2n_2}{2N}\)

\(h_0=N(1-\hat{f})^2\)

\(h_1=2N\hat{f}(1-\hat{f})\) et

\(h_2=N\hat{f}^2\)

Le test HWE II

La statistique de test mesure l’écart entre les effectifs observés et les effectifs attendus : \(t_{HWE}=\sum_{i=0}^{2}\frac{n_i-h_i}{2h_i}\)

Si le HWE se vérifie, alors \(t_{HWE}\) suit approximativement une distribution \(\chi²\) avec 1 df, qui est utilisée pour dériver une valeur \(p\).

Pour un échantillon de petite taille ou des variants très rares, une distribution de statistiques de test basée sur des permutations doit être utilisée, par exemple en utilisant le package R HardyWeinberg.

Parenté génétique : IBS

Identical-by-state (IBS) : Identique par état.

Deux allèles sont IBS s’il sont identiques sans forcément provenir d’un ancêtre commun.

A l’échelle de l’individu, il s’agit d’une mesure de similarité génétique utilisée pour détecter

  • des individus apparentés,

  • des échantillons dupliqués ou

  • des erreurs dans les données.

L’IBS mesure le nombre d’allèles identiques partagés entre deux individus pour un ensemble de SNPs, indépendamment de leur origine ancestrale.

IBS Exemple :

Pour un SNP donné :

Individu A Individu B IBS
A/A A/A 2
A/G A/G 2
A/G A/A 1
A/G G/G 1
A/A G/G 0

Calcul de l’IBS

Pour chaque paire d’individus, PLINK compare les génotypes sur les SNPs disponibles et calcule l’IBS moyen (ou distance génétique).

  • \(IBS_0\) : Proportion de SNPs où aucun allèle n’est partagé.

  • \(IBS_1\) : Proportion de SNPs avec un allèle partagé.

  • \(IBS_2\) : Proportion de SNPs avec deux allèles partagés.

  • PLINK peut aussi donner la distance génétique IBS :

\(distance= 1 - \frac{\text{nombre d’allèles partagés}}{2 \times \text{nombre de SNPs comparés}}\)

Parenté génétique : IBD

Identical-by-descent (IBD) : Identique par descendance.

Deux allèles sont IBD s’ils proviennent d’un ancêtre commun sans mutation intermédiaire.

IBD : L’identité repose sur la transmission généalogique.

Calcul de l’IBD

L’IBD est estimé statistiquement à partir des données génotypiques de paires d’individus. La méthode standard consiste à estimer les probabilités IBD (Z0, Z1, Z2) :

Probabilité Signification
Z0 Proba qu’ils partagent 0 allèle IBD
Z1 Proba qu’ils partagent 1 allèle IBD
Z2 Proba qu’ils partagent 2 allèles IBD

À partir de cela, on peut estimer la proportion d’allèles IBD partagés :

\(\text{PI_HAT} = Z1 \times 0.5 + Z2 \times 1.0\)

Interprétation de PI_HAT

Relation PI_HAT ~ Z0 Z1 Z2
Jumeaux monozygotes 1.00 0 0 1
Parent – enfant 0.50 0 1 0
Frères/sœurs 0.50 0.25 0.5 0.25
Demi-frères/sœurs 0.25 0.5 0.5 0
Cousins éloignés 0.125 ~0.75 ~0.25 ~0
Non apparentés ~0.00 ~1 ~0 ~0

Les structures cryptiques de population

Plusieurs méthodes d’estimation de la parenté examinées précedemment reposent sur l’hypothèse d’une population homogène, sans structure génétique.

Une structure génétique de population est présente dans l’échantillon si celui-ci peut être divisé en groupes de telle sorte que les individus d’un groupe sont, en moyenne, plus semblables génétiquement entre eux qu’avec les individus des autres groupes. Les populations éloignées géographiquement forment des sous-populations homogènes.

Réaliser une GWAS suppose que la population étudiée est homogène.
